hAI.HermesPortainer

Deployment

This project uses Docker Compose for deployment. Refer to the GitHub repository for full configuration details.

LLM Provider: 9router

Both containers share the hermes-home volume, so provider config lives in <hermes-home>/.hermes/<profile>/config.yaml. OPENAI_API_KEY + OPENAI_BASE_URL register 9router automatically under the openai-api provider; the model dropdown shows what 9router's /v1/models returns for your key.

Custom provider with model allowlist

custom_providers:
  - name: 9router
    base_url: https://9router.arbeitermili.eu/v1
    api_key: "${OPENAI_API_KEY}"
    models:
      - all_coding
      - <weitere model ids von 9router>

After editing, run docker exec -it hermes-agent hermes doctor --fix.
